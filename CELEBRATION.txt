┌──────────────────────────────────────────────────────────────────────────┐
│  🚀  USAGE EXAMPLES                                                      │
└──────────────────────────────────────────────────────────────────────────┘

  Create a model card:
    $ aim card create my-llm --version 1.0.0 --description "My LLM" \
      --model-type "LLM" --architecture "Transformer" --output card.json

  Generate a template:
    $ aim card template --template-type llm --output llm_card.json

  Validate a card:
    $ aim card validate card.json --strict

  Convert formats:
    $ aim card convert card.json card.yaml
    $ aim card convert card.yaml card.md

  Show a card:
    $ aim card show card.json --format markdown

  Store in vault:
    $ aim store my-model model.pt --format pytorch --description "v1.0"

  List models:
    $ aim list

  Get model:
    $ aim get my-model --output restored.pt

  Show stats:
    $ aim stats
