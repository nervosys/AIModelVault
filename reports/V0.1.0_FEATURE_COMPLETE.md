### CLI Commands (19)
```bash
# Version Control (5)
aim add <path>                  # Add model to vault
aim commit <model> -m "msg"     # Create version
aim list                        # List models
aim show <model>                # Show details
aim rollback <model> --version N # Rollback version

# Model Cards (8)
aim card create <output>        # Create card
aim card show <input>           # Display card
aim card validate <input>       # Validate card
aim card convert <input> --to yaml # Convert format
aim card template --type llm    # Generate template
aim card attach <model> --card <path> # Attach to vault
aim card extract <model> --output <path> # Extract from vault
aim card generate <model>       # Generate from metadata

# Cloud Storage (4)
aim cloud push <model> --provider s3 # Upload to cloud
aim cloud pull <model> --provider s3 # Download from cloud
aim cloud list --provider s3    # List cloud models
aim cloud config --provider s3  # Configure credentials

# Format Conversion (1)
aim convert <input> --to onnx   # Convert format

# MCP Server (1)
aim mcp                         # Start MCP server
```
