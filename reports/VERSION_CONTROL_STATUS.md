## 🎨 Feature Highlights

### Sequential Versioning
```
v1 → v2 → v3 → v4 → v5 ...
```
Automatic numbering with unique checkpoint IDs

### Branching
```
v1 (base)
│
v2 (fine-tuned)
├─ v3 (exp-a)
└─ v4 (exp-b)
```
Parallel development with parent-child relationships

### Lineage Tracking
```
v1: 2024-10-01 (pre-training)
  v2: 2024-10-15 (fine-tuning)
    v3: 2024-10-22 (chat-tuning)
      v5: 2024-11-05 (rlhf)
```
Complete ancestry from root to current

### Version Comparison
```
┌──────────────┬──────────────┬──────────────┐
│ Metric       │ v3           │ v5           │

│ Date         │ 2024-10-22   │ 2024-11-05   │
│ Epochs       │ 40           │ 48           │
└──────────────┴──────────────┴──────────────┘
```
Side-by-side metadata and metrics

### Cleanup
```
Before: 118 GB (15 versions)

```
Retention policies with storage optimization

## 🚀 Usage Examples

### Basic
```rust
// Store v1
let v1 = vault.store_model(name, data, meta, None)?;

// Store v2 from v1
let v2 = vault.store_model(name, data2, meta2, Some(1))?;

// Get latest
let latest = vault.get_model(name, None)?;

// Get v1
let v1_data = vault.get_model(name, Some(1))?;
```

### Branching
```rust
let base = vault.store_model(name, data, meta, None)?;
let exp_a = vault.store_model(name, data_a, meta_a, Some(base.version))?;
let exp_b = vault.store_model(name, data_b, meta_b, Some(base.version))?;
```

### Time Travel
```rust
// Rollback to v3
let old = vault.get_model(name, Some(3))?;
deploy(&old)?;
```

### Cleanup
```rust
// Keep last 5 versions
vault.cleanup_old_versions(name, 5)?;
```
